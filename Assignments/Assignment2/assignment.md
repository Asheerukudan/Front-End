## Assignment 1: Customer Information Table

Create a webpage that displays a list of customers in a table.

### Requirements

1. Add a heading: **Customer Records**.
2. Create a table with the following columns: S/N, Customer Name, Customer ID, Email and Phone Number.
3. Add at least 10 customer records.
4. Use `<thead>`, `<tbody>`, `<tr>`, `<th>` and `<td>` appropriately.
5. Add a table heading that spans all five columns using `colspan`.
6. Group some customer records by month using another row with `colspan`.
7. Use `rowspan` to demonstrate how a cell can occupy multiple rows.
8. Add a **Back to Top** link that takes the user to the beginning of the page.

## Assignment 2: Personal Portfolio Webpage

Create a simple personal portfolio webpage.

### Requirements

1. Add a welcome heading with your name.
2. Create navigation links for Home, About Me, My Skills and Contact.
3. Make each navigation link point to its corresponding section using HTML IDs.
4. Add an About Me section containing at least two paragraphs.
5. Add a My Skills section listing at least five skills.
6. Add a Contact section containing your email address and phone number.
7. Add a link to your LinkedIn profile or another social media profile.
8. Add a **Back to Top** link.
9. Use semantic HTML elements such as `<header>`, `<nav>`, `<main>`, `<section>` and `<footer>`.
