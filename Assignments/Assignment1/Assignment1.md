# HTML Practical Take-Home Assignment

**Topic:** HTML Basics, Headings, Paragraphs, Lists, Formatting Tags and HTML Entities

**Instructions:**

- Attempt all  questions.
- Save each question in a separate `.html` file.
- Open your files in a web browser to confirm that they work correctly.

### **Question 1: Personal Profile Page**

Create a simple user profile webpage containing:

1. Your full name as the main heading (`h1`).
2. Your occupation or career interest as an `h2`.
3. A short introduction about the user.
4. Hobbies using a list.
5. Educational qualifications using an ordered list.
6. Use bold and italic formatting to highlight important information.

### **Question 2: My Favourite Things**

Create a webpage titled **My Favourite Things**.

Your webpage should contain:

1. An `h1` heading titled "My Favourite Things".
2. Three `h2` headings:
   - Favourite Foods
   - Favourite Movies
   - Favourite Colours
3. Under each heading, provide at least four items using unordered lists.
4. Use different list styles (`disc`, `circle`, and `square`) for the three lists.
5. Underline your favourite item in each category.

### **Question 3: Mathematics and HTML Formatting**

Create a webpage titled **Basic Mathematical Expressions**.

Display the following mathematical expressions correctly using HTML formatting tags:

1. H₂O
2. CO₂
3. X² + Y²
4. A² + B² = C²
5. 10² = 100

Also include:

- A heading for each expression.
- A paragraph explaining the difference between subscript (`sub`) and superscript (`sup`).
- Use the deleted text tag (`del`) to show an old price of ₦5,000 crossed out and a new price of ₦3,500.

### **Question 4: Design a Simple Course Information Page**

Create a webpage for a computer training centre advertising its available courses.

Your webpage must contain:

1. A main heading with the name of the training centre.
2. A paragraph introducing the training centre.
3. A heading titled "Available Courses".
4. An unordered list containing at least five courses.
5. An ordered list showing the steps to register for a course.

**Submission Requirements**

- Four separate HTML files.
- Each file must have a proper HTML document structure (`html`, `head`, `title`, and `body`).
- Ensure all webpages display correctly in a browser.
